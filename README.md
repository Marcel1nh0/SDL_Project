Este projeto foi desenvolvido em linguagem C utilizando a biblioteca SDL3 e a extensão SDL_image com o objetivo de estudar fundamentos de programação, manipulação de memória e renderização gráfica.

O programa funciona como um visualizador simples de imagens, permitindo que o usuário informe o caminho de um arquivo PNG pelo terminal para que a imagem seja carregada e exibida em uma janela gráfica criada pela SDL3.

Funcionalidades
Inicialização de sistema gráfico utilizando SDL3
Criação de janela redimensionável
Entrada de caminho de arquivo pelo terminal
Manipulação dinâmica de strings e memória com malloc/calloc
Carregamento de imagens PNG
Conversão de SDL_Surface para SDL_Texture
Renderização da imagem na janela
Loop de eventos para manter a aplicação em execução
Encerramento seguro e liberação de recursos da memória
Objetivos do Projeto

O principal foco deste projeto foi aprofundar conhecimentos em:

Programação em C
Ponteiros e alocação dinâmica de memória
Manipulação de strings
Estruturas de repetição e validação de entrada
Uso de bibliotecas externas
Conceitos básicos de renderização gráfica
Estrutura de aplicações orientadas a eventos

Além disso, o projeto serviu como introdução prática ao desenvolvimento gráfico utilizando SDL3, tecnologia bastante utilizada em jogos, aplicações multimídia e ferramentas interativas.

Tecnologias Utilizadas
Linguagem C
SDL3
SDL3_image
